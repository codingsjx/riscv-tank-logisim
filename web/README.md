# 坦克世界大战 · 浏览器试玩

玩法由 `dist/rom.js` 的 RISC-V 机器码驱动，源码来自仓库根目录的 `software/tank.s`。
`engine.js` 是指令级解释器，界面负责输入、显示与节奏；Logisim 流水线时序仍以原工程为准。

运行：`node tools/preview.mjs`，打开终端打印的本地地址。

更新机器码与测试数据：`python tools/export_rom.py`
验证：`node --test tests/*.test.mjs`

- 方向键 / WASD 移动，空格射击，P 暂停，R 重开，Enter 开始或继续；所有移动输入统一至少间隔 280ms，点按/长按开火统一遵守 190ms 间隔，默认炮弹约每 260ms 前进一格。
- 手机使用屏幕方向键和开火键。
- 训练 / 进阶 / 困难分别有 2 / 4 / 6 辆敌军，每 4 / 3 / 2 拍行动。
- 训练关最多两辆敌军同时在场，进阶和困难关最多三辆；后续敌军分批补入，剩余计数包含后备敌军。
- 玩家从基地旁出生，金边护墙需要两次命中才破；普通砖墙仍需一次。
- 玩家和敌军炮弹同格或迎面交叉时相互抵消。
- 切换关卡会重新准备战场；子弹速度与战斗节奏可以分别调整，默认子弹每两拍移动一格。
- 所有关卡混编普通小兵与精英怪，分别有 1 / 3 点生命；头顶格条显示剩余生命。
- 只有击杀精英怪才掉落升级星，接触后自动拾取；按 E 或按钮消耗道具。
- 一级弹药容量 2 → 3，二级伤害 1 → 2；满级后恢复一条生命，满血时保留道具。
- 背包最多 3 枚，未拾取的后续掉落会累积在原位置；重开清空装备和掉落。

测试以 274 个检查点对比 Python 参考解释器和浏览器解释器的全部寄存器、RAM、PC 与指令计数，覆盖三个关卡。

静态部署目录为 `dist/`，无第三方运行依赖。

从仓库根目录启动：`node web/tools/preview.mjs`。修改汇编后运行 `python web/tools/export_rom.py`，再运行 `python tools/export_browser_standalone.py` 更新可双击试玩文件。
